# Первый проход индексации метрических книг Фёдоровки — план выполнения

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать проверяемый журнал индексаций и завершить первый проход по книге «Федоровка 1845,1846гг .xlsx» только для прямой линии Надежды Виноградовой.

**Architecture:** GEDCOM остаётся источником истины приложения. `docs/indexing-log.md` хранит охват и выводы по внешним индексам; `AGENTS.md` требует его проверять и пополнять. Запись принимается только по нескольким идентифицирующим признакам; отрицательный результат фиксируется в журнале и не создаёт родственных связей.

**Tech Stack:** Markdown, GEDCOM 5.5.1, `@oai/artifact-tool`, Vitest, Vite.

## Global Constraints

- Источник данных — `public/fedorovka_family.ged`, медиа — `public/photos/`.
- Отбирать только доказательства прямой линии `@I1@`, её супругов, детей и необходимых связующих персон.
- Факт без надёжной идентификации не создаёт человека, семью, дату или место; версия получает `_CONF B|C` и `_TODO`.
- Принятая запись требует `SOUR` с архивным происхождением, файлом, вкладкой и строкой индекса.
- Не перезаписывать пользовательские изменения `public/fedorovka_family.ged` и `public/photos/bekin_red_book_lanin_p69.webp`.
