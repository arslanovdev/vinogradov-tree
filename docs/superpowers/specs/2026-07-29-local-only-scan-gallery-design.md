# Локальная галерея сканов — дизайн

## Цель

Оставить временную галерею доступной для локальных генеалогических исследований, но полностью исключить её из production-интерфейса и production-сервера.

## Согласованное решение

- В `import.meta.env.DEV` подключаются кнопка галереи и компонент `ScanGallery`.
- В production `App.svelte` не импортирует компонент и не рендерит кнопку.
- Временный Vite middleware для `/i294op1d587` регистрируется только во время dev-сервера.
- Остальной интерфейс, дерево и production-данные не меняются.

## Проверка

- `npm test` и `npm run build` должны проходить.
- В dev-интерфейсе должна оставаться кнопка «Временная галерея сканов».
- В production-сборке не должно быть ссылки на компонент галереи или временный маршрут.
- Локальный маршрут WebP-сканов должен продолжать работать при `npm run dev`.
